## What this repo is

A Next.js (App Router) web application for a client, deployed on Vercel with Supabase as
the backend. Feature areas visible under `app/`:

`achievements` · `admin` · `ai-practice` · `api` · `enrichment` · `exams` · `handbook` ·
`leaderboard` · `league` · `letters` · `login` · `more`

The shape (exams, practice, leaderboard, league, achievements) is a learning/training
platform with gamification and an admin back office. **[OWNER] confirm the exact domain
and who the end users are.**

## Common commands

```bash

```

## Conventions and gotchas

- **`npm run build` must pass before anything merges.** This project has previously
  broken on Vercel because server-only code leaked into a client bundle (see the commit
  "Fix Vercel build: split letters-video pure helpers from server loaders"). When adding
  helpers, keep pure functions separate from server loaders/actions.
- Environment config lives in `.env.local` (gitignored); `.env.local.example` documents
  the required keys. Never commit real values.
- Supabase changes belong in `supabase/` (migrations), not ad-hoc SQL against prod.
- Anthropic and ElevenLabs calls cost money per request — be careful with loops and
  retries in `ai-practice`.
